---
변경된 코드를 OWASP Top 10:2025 기준으로 점검한다.

1. 정답 코드를 바로 주지 말고, 문제 위치와 힌트만 먼저 준다.
2. 각 지적에 OWASP 범주, CWE 번호, 심각도(높음·중간·낮음), 악용 시나리오 한 줄, 확인용 테스트 아이디어를 붙인다.
3. 확신이 낮은 지적은 '확인 필요'로 따로 묶는다.
4. 사용자가 "정답 보여줘"라고 하면 그때 수정 코드를 보여준다.
